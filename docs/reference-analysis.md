# 参考项目简析

参考仓库 `EliseSo/pindou-skill` 是一个面向 Claude Code / ChatGPT 图像生成工作流的 skill。它把用户图片转换为带 MARD 色号、坐标和用量图例的拼豆图纸，并生成成品、钥匙扣、冰箱贴、立牌四种产品效果图以及四宫格。

其核心流程是：识别主体比例与关键颜色，先形成颜色计划，再生成图纸并检查比例、颜色和可读性；以通过检查的图纸和成品图为主版本，为同一拼豆对象添加不同配件或场景。它特别强调最终 3:4 画布只能通过留白扩展，不能拉伸或裁切主体，同时要求预览之间的轮廓与配色一致。

值得借鉴的是比例锁定、颜色计划、图纸与预览分步校验、可追溯输出，以及四种产品场景。参考实现更适合一次性的生成式任务：它依赖图像模型，精确色号文字与豆子计数无法天然保证，用户也不能在浏览器中逐格修正。

BeadCraft Studio 将工作流改造成确定性的本地 Web 工具：Canvas 解码与采样、LAB/CIEDE2000 匹配、二维 grid、精确统计、逐格编辑和矢量/表格/工程文件导出全部在浏览器完成。四类产品预览由同一 grid 本地合成。由于参考仓库只提供色号家族和少量锚点，没有足够可信的完整官方色卡，MVP 使用清楚标记的 DEMO palette，并提供 CSV palette 导入接口。
